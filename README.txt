PERSONAL EXPENSE TRACKER
========================

Requirements:
1. MAMP
2. PHP
3. MySQL
4. Web browser

SETUP INSTRUCTIONS
------------------

1. Install and open MAMP.

2. Copy the folder:
   Personal_Expense_Tracker

   into:
   C:\MAMP\htdocs\

3. Open phpMyAdmin:
   http://localhost/phpMyAdmin/

4. Create a new database named:
   personal_expense_tracker

5. Select the database and click "Import".

6. Import the file:
   personal_expense_tracker.sql

7. Make sure MAMP Apache and MySQL are running.

8. Open the project in the browser:
   http://localhost/Personal_Expense_Tracker/

9. Register a new account and log in.

PROJECT FEATURES
----------------
- User Registration & Login
- Dashboard
- Transaction Management
- Accounts Management
- Budgets
- Financial Goals
- Spending Insights
- Financial Calendar
- Debt & Loan Tracker
- Medical Expense Tracker
- Add/Edit/Delete records
- Financial summaries
